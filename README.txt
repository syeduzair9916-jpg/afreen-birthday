AFREEN ZOHRA — BIRTHDAY WEBSITE

How to view:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or another browser.
3. It works on mobile and desktop. No installation or internet connection is required.

How to personalise:
- Open index.html in VS Code.
- Search for the letter text inside <div id="letterText"> and edit the paragraphs.
- Search for "What makes you special" to edit the four appreciation cards.
- Save and refresh the browser.

To share it as a public link:
Upload the extracted folder to a static hosting service such as GitHub Pages or Netlify.
